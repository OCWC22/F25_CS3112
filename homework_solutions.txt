### Problem 7: Fibonacci Numbers and the Golden Ratio

**What we need to prove:** Show that the golden ratio φ and its conjugate φ̂ both satisfy the equation x² = x + 1.

**Formal Restatement:** Show that φ² = φ + 1 and φ̂² = φ̂ + 1, where φ = (1 + √5)/2 and φ̂ = (1 - √5)/2.

**How to Read This Out Loud and What It Means (Step-by-Step Explanation):**
- **"φ" (phi):** This is the golden ratio, approximately 1.618
- **"φ̂" (phi-hat):** This is the conjugate of the golden ratio, approximately -0.618
- **"x² = x + 1":** This equation says "x squared equals x plus one"
- **What we're proving:** If you plug in φ or φ̂ for x, the equation will be true

**Proof for φ:**

Let's calculate φ² and φ + 1 separately and see if they're equal.

φ = (1 + √5)/2

Step 1: Calculate φ²
φ² = [(1 + √5)/2]²
   = (1 + √5)² / 2²
   = (1 + 2√5 + 5) / 4
   = (6 + 2√5) / 4
   = (3 + √5) / 2

Step 2: Calculate φ + 1
φ + 1 = (1 + √5)/2 + 1
      = (1 + √5 + 2)/2
      = (3 + √5)/2

Step 3: Compare them
φ² = (3 + √5)/2
φ + 1 = (3 + √5)/2

Therefore: φ² = φ + 1 ✓

**Proof for φ̂:**

φ̂ = (1 - √5)/2

Step 1: Calculate φ̂²
φ̂² = [(1 - √5)/2]²
    = (1 - √5)² / 2²
    = (1 - 2√5 + 5) / 4
    = (6 - 2√5) / 4
    = (3 - √5) / 2

Step 2: Calculate φ̂ + 1
φ̂ + 1 = (1 - √5)/2 + 1
       = (1 - √5 + 2)/2
       = (3 - √5)/2

Step 3: Compare them
φ̂² = (3 - √5)/2
φ̂ + 1 = (3 - √5)/2

Therefore: φ̂² = φ̂ + 1 ✓

**Conclusion:** Both the golden ratio φ and its conjugate φ̂ satisfy the equation x² = x + 1.

### Problem 8: Fibonacci Number Formula

**What we need to prove:** Prove by induction that the ith Fibonacci number satisfies Fᵢ = (φⁱ - φ̂ⁱ)/√5.

**Formal Restatement:** ∀ integers i ≥ 0, Fᵢ = (φⁱ - φ̂ⁱ)/√5.

**How to Read This Out Loud and What It Means (Step-by-Step Explanation):**
- **"∀ i ≥ 0":** For all non-negative integers i
- **"Fᵢ":** The ith Fibonacci number
- **"(φⁱ - φ̂ⁱ)/√5":** Phi to the power i, minus phi-hat to the power i, all divided by the square root of 5

**Base Case (i = 0):**
F₀ = 0 (by definition)
(φ⁰ - φ̂⁰)/√5 = (1 - 1)/√5 = 0/√5 = 0
Therefore: F₀ = (φ⁰ - φ̂⁰)/√5 ✓

**Base Case (i = 1):**
F₁ = 1 (by definition)
(φ¹ - φ̂¹)/√5 = [(1 + √5)/2 - (1 - √5)/2]/√5
= [(1 + √5 - 1 + √5)/2]/√5
= [(2√5)/2]/√5
= √5/√5 = 1
Therefore: F₁ = (φ¹ - φ̂¹)/√5 ✓

**Inductive Step:**
Assume the formula holds for all k ≤ n (strong induction). Show it holds for n + 1.

By the Fibonacci definition: Fₙ₊₁ = Fₙ + Fₙ₋₁

By the inductive hypothesis:
Fₙ = (φⁿ - φ̂ⁿ)/√5
Fₙ₋₁ = (φⁿ⁻¹ - φ̂ⁿ⁻¹)/√5

Therefore:
Fₙ₊₁ = (φⁿ - φ̂ⁿ)/√5 + (φⁿ⁻¹ - φ̂ⁿ⁻¹)/√5
      = (φⁿ + φⁿ⁻¹ - φ̂ⁿ - φ̂ⁿ⁻¹)/√5
      = (φⁿ⁻¹(φ + 1) - φ̂ⁿ⁻¹(φ̂ + 1))/√5

Since φ² = φ + 1 and φ̂² = φ̂ + 1:
Fₙ₊₁ = (φⁿ⁻¹(φ²) - φ̂ⁿ⁻¹(φ̂²))/√5
      = (φⁿ⁺¹ - φ̂ⁿ⁺¹)/√5

**Conclusion:** By induction, Fᵢ = (φⁱ - φ̂ⁱ)/√5 for all i ≥ 0.

### Problem 2: Strassen's Algorithm Multiplication Count

**What we need to solve:** How many scalar multiplications does Strassen's algorithm perform when multiplying two n × n matrices, where n is a power of 2?

**Formal Restatement:** Find the total number of scalar multiplications in Strassen's algorithm for input size n = 2^k.

**How to Read This Out Loud and What It Means (Step-by-Step Explanation):**
- **"scalar multiplications":** Basic multiplications of individual numbers
- **"n is a power of 2":** n = 2, 4, 8, 16, ... so we can keep dividing by 2
- **"total number":** We need to count all multiplications at all levels of recursion

**Step 1: Understand the recurrence relation**

From the algorithm, we know:
- Base case (n = 1): 1 multiplication
- Recursive case (n > 1): 7 multiplications of (n/2) × (n/2) matrices

This gives us the recurrence: M(n) = 7M(n/2), where M(1) = 1

**Step 2: Solve the recurrence**

Let's expand for a few values to see the pattern:

M(1) = 1
M(2) = 7M(1) = 7 × 1 = 7
M(4) = 7M(2) = 7 × 7 = 49 = 7²
M(8) = 7M(4) = 7 × 49 = 343 = 7³
M(16) = 7M(8) = 7 × 343 = 2401 = 7⁴

**Step 3: Find the general formula**

The pattern shows: M(n) = 7^(log₂ n)

**Step 4: Verify this formula**

Let's express log₂ n as k, so n = 2^k:
M(2^k) = 7^k = 7^(log₂ n)

**Step 5: Alternative form**

We can also write this as:
M(n) = n^(log₂ 7)

This is because:
7^(log₂ n) = (2^(log₂ 7))^(log₂ n)
          = 2^((log₂ 7)(log₂ n))
          = (2^(log₂ n))^(log₂ 7)
          = n^(log₂ 7)

**Final Answer:** Strassen's algorithm performs n^(log₂ 7) ≈ n^2.807 scalar multiplications when multiplying two n × n matrices, where n is a power of 2.

#### Problem 1a: T(n) = 2T(n/4) + 1

**What we need to solve:** Use the substitution method to give tight asymptotic bounds for T(n) = 2T(n/4) + 1.

**Formal Restatement:** Find Θ notation for the recurrence T(n) = 2T(n/4) + 1.

**How to Read This Out Loud and What It Means (Step-by-Step Explanation):**
- **"T(n) = 2T(n/4) + 1":** The running time is twice the time for a quarter-sized problem, plus constant time
- **"substitution method":** We guess a solution and prove it by induction
- **"tight asymptotic bounds":** We want to find the exact growth rate, not just upper or lower bounds

**Step 1: Draw a recursion tree to guess the solution**

Level 0: 1
Level 1: 2 × 1 = 2
Level 2: 4 × 1 = 4
Level 3: 8 × 1 = 8
...
Level k: 2^k × 1

Tree height: log₄ n
Total: sum of geometric series = 2^(log₄ n + 1) - 1 = Θ(n^(log₄ 2)) = Θ(n^0.5) = Θ(√n)

**Step 2: Guess T(n) = O(√n)**

Let's prove T(n) ≤ c√n for some constant c > 0.

**Inductive hypothesis:** Assume T(k) ≤ c√k for all k < n.

**Substitution:**
T(n) = 2T(n/4) + 1
     ≤ 2c√(n/4) + 1
     = 2c(√n/2) + 1
     = c√n + 1

We need c√n + 1 ≤ c√n, which is never true for any c > 0.

**Step 3: Refine our guess to T(n) = O(√n) - b**

Let's try T(n) ≤ c√n - b for some constants c > 0 and b > 0.

**Substitution:**
T(n) = 2T(n/4) + 1
     ≤ 2(c√(n/4) - b) + 1
     = 2(c(√n/2) - b) + 1
     = c√n - 2b + 1

We need c√n - 2b + 1 ≤ c√n - b, which simplifies to -2b + 1 ≤ -b, or 1 ≤ b.

So if we choose b = 1, the inequality holds.

**Final Answer:** T(n) = Θ(√n)

- **"T(n) = 4T(n/2) + n":** The running time is four times the time for a half-sized problem, plus linear time
- **"substitution proof fails":** Our initial guess T(n) ≤ cn² doesn't work with induction
- **"subtract a lower-order term":** We need to adjust our guess to T(n) ≤ cn² - dn

**Part 1: Show that T(n) ≤ cn² fails**

Assume T(k) ≤ ck² for all k < n.

**Substitution:**
T(n) = 4T(n/2) + n
     ≤ 4c(n/2)² + n
     = 4c(n²/4) + n
     = cn² + n

We need cn² + n ≤ cn², which simplifies to n ≤ 0, which is never true for n > 0.

**Part 2: Show that T(n) ≤ cn² - dn works**

Let's try T(n) ≤ cn² - dn for some constants c > 0 and d > 0.

T(n) = 4T(n/2) + n
     ≤ 4[c(n/2)² - d(n/2)] + n

     = cn² - 2dn + n

We need cn² - (2d - 1)n ≤ cn² - dn, which simplifies to:
-(2d - 1)n ≤ -dn
n ≤ dn
1 ≤ d

So if we choose d = 1, the inequality holds for all n ≥ 1.

**Final Answer:** The solution is T(n) = Θ(n²), and the induction proof works with the adjusted guess T(n) ≤ cn² - dn where d = 1.

#### Problem 4-1f: A = lg(n!), B = lg(nⁿ)

**Step 1: Simplify lg(nⁿ)**

lg(nⁿ) = n lg n

**Step 2: Use Stirling's approximation for n!**

n! ≈ √(2πn)(n/e)ⁿ

**Step 3: Calculate lg(n!)**

lg(n!) ≈ lg(√(2πn)(n/e)ⁿ)
       = lg(√(2πn)) + lg((n/e)ⁿ)
       = (1/2)lg(2πn) + n lg(n/e)
       = (1/2)lg(2πn) + n(lg n - lg e)
       = n lg n + (1/2)lg(2πn) - n lg e
       = n lg n + (1/2)lg(2πn) - n lg e

**Step 4: Compare with lg(nⁿ) = n lg n**

lg(n!) = n lg n + lower-order terms
lg(nⁿ) = n lg n
