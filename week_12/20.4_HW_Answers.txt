20.4-3 - Detect a simple cycle in an undirected graph in O(V) (independent of |E|)

Use either quick logic or early-exit DFS:

• Logic approach: An undirected graph has a cycle iff |E| ≥ |V| in at least one connected component. If you know |E| per component, you're done instantly.

• Early-exit DFS approach: Run DFS but stop as soon as you see one back edge (an edge to an already-GRAY ancestor). If a cycle exists, you'll encounter it before you've explored more than |V| edges; otherwise an acyclic undirected graph (forest) has at most |V|−1 edges overall, giving O(V) time. (This "early stop" argument is the standard way this exercise attains O(V) worst-case.)

Handy BFS/DFS complexities recap:

• BFS with adjacency list: Θ(V+E); with adjacency matrix: Θ(V²).

• DFS: Θ(V+E); edge types as above; undirected graphs have only tree/back edges.
