Q1. Given P(X|Y) = 1/2 and P(Y) = 1/4, find P(X n Y).
- Formula: P(X n Y) = P(X|Y) * P(Y)
- Calculation: (1/2) * (1/4) = 1/8
- Answer: 1/8

---------------------------------

Q2. Given P(X) = 1/3, P(Y) = 1/5, and P(X n Y) = 1/6, find P(X|Y).
- Formula: P(X|Y) = P(X n Y) / P(Y)
- Calculation: (1/6) / (1/5) = 5/6
- Answer: 5/6

---------------------------------

Q3. P(A on T1)=0.25, P(A on T2)=0.15, P(A on both)=0.10. Find P(A on T2 | A on T1).
- Formula: P(T2|T1) = P(T1 n T2) / P(T1)
- Calculation: 0.10 / 0.25 = 0.4
- Answer: 40%

Q4. P(Condition)=0.001. Test: 1% false neg, 4% false pos. Find P(Condition | Positive).
- This is a Bayes' Theorem problem.
- P(C)=0.001, P(T|C)=0.99, P(T|C')=0.04
- P(C|T) = [P(T|C)P(C)] / [P(T|C)P(C) + P(T|C')P(C')]
- P(C|T) = (0.99*0.001) / [(0.99*0.001) + (0.04*0.999)]
- P(C|T) = 0.00099 / 0.04095
- Answer: approx 2.42%

---------------------------------

Q5. A, B independent, P(A)=1/3, P(B)=1/4. Find P(A|B).
- By definition of independence, P(A|B) = P(A).
- Answer: 1/3

Q9. Prove Bayes' Theorem for n=2.
- Start with P(B1|A) = P(A n B1) / P(A).
- The numerator is P(A|B1)P(B1).
- The denominator P(A) expands to P(A|B1)P(B1) + P(A|B2)P(B2) because B1 and B2 partition the space.
- Substituting these gives the theorem.

---------------------------------

Q10. Prove the full version of Bayes' Theorem.
- This extends the logic from n=2. The numerator P(A n Bk) is P(A|Bk)P(Bk). The denominator P(A) is expanded using the Law of Total Probability over the whole partition B1...Bn.

Q21. A, B independent, A n B = {}. What must be true?
- P(A n B) = P(A)P(B). Since A n B is empty, P(A n B) = 0.
- So, P(A)P(B) = 0.
- Answer: Either P(A) = 0 or P(B) = 0.

Q22. Prove A and B' are independent if A and B are.
- We know P(A n B') = P(A) - P(A n B).
- Since A,B are independent, this is P(A) - P(A)P(B).
- Factoring gives P(A)(1 - P(B)), which is P(A)P(B').
- The condition is met.

Q26. Pairwise vs. Mutual Independence.
- Example: Toss coin twice. A=1st is H, B=2nd is H, C=exactly one H.
- P(A)=1/2, P(B)=1/2, P(C)=1/2.
- They are pairwise independent (e.g., P(A n B)=1/4 = P(A)P(B)).
- Not mutually independent: P(A n B n C)=0, but P(A)P(B)P(C)=1/8.

Q33. Gambler's Ruin.
- Let Pk = prob of ruin starting with $k. Win $1 with p=1/6, lose $1 with q=5/6.
- The prob of ruin from state k is the weighted average of ruin from the next states.
- This gives the recurrence relation: Pk = p*P(k+1) + q*P(k-1).
- Derivation: Pk = (1/6)P(k+1) + (5/6)P(k-1).
