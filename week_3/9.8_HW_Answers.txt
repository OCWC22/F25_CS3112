Q1. In any sample space S, what is P(∅)?
- Step 1: The symbol ∅ represents the empty set, an impossible event.
- Step 2: The probability of an impossible event is 0.
- Answer: P(∅) = 0.

----------------------------------------------------
Q2. Given: A, B, C are mutually exclusive, A ∪ B ∪ C = S, P(A)=0.3, P(B)=0.5.
(a) Find P(A ∪ B).
- Step 1: Since A and B are mutually exclusive, P(A ∪ B) = P(A) + P(B).
- Step 2: P(A ∪ B) = 0.3 + 0.5 = 0.8.
- Answer: 0.8.

(b) Find P(C).
- Step 1: Since A, B, C form a partition of S, P(A) + P(B) + P(C) = 1.
- Step 2: 0.8 + P(C) = 1 ⇒ P(C) = 1 - 0.8 = 0.2.
- Answer: 0.2.

(c) Find P(Aᶜ).
- Step 1: The probability of a complement is P(Aᶜ) = 1 - P(A).
- Step 2: P(Aᶜ) = 1 - 0.3 = 0.7.
- Answer: 0.7.

Q3. Given: A, B are mutually exclusive, A ∪ B ∪ C = S, P(A)=0.4, P(B)=0.25.
(a) Find P(A ∪ B).
- Step 1: P(A ∪ B) = P(A) + P(B) = 0.4 + 0.25 = 0.65.
- Answer: 0.65.

(b) Is P(C)=0.2 possible?
- Step 1: If A, B, C partition S, then P(C) = 1 - P(A ∪ B) = 1 - 0.65 = 0.35.
- Step 2: A value of P(C)=0.2 would mean the total probability is 0.4 + 0.25 + 0.2 = 0.85, which is not 1.
- Answer: No, it is not possible. P(C) must be 0.35.

Q4. Given: P(A)=0.8, P(B)=0.7, P(A ∩ B)=0.6.
- Step 1: Use the formula P(A ∪ B) = P(A) + P(B) - P(A ∩ B).
- Step 2: P(A ∪ B) = 0.8 + 0.7 - 0.6 = 0.9.
- Answer: 0.9.

Q5. Given: P(A)=0.6, P(Bᶜ)=0.4, P(A ∩ B)=0.2.
- Step 1: Find P(B) = 1 - P(Bᶜ) = 1 - 0.4 = 0.6.
- Step 2: P(A ∪ B) = P(A) + P(B) - P(A ∩ B) = 0.6 + 0.6 - 0.2 = 1.0.
- Answer: 1.0.

Q6. Given: P(U)=0.3, P(V)=0.6, P(Uᶜ ∪ Vᶜ)=0.4.
- Step 1: By De Morgan's Law, P(Uᶜ ∪ Vᶜ) = P((U ∩ V)ᶜ) = 0.4.
- Step 2: P(U ∩ V) = 1 - P((U ∩ V)ᶜ) = 1 - 0.4 = 0.6.
- Step 3: P(U ∪ V) = P(U) + P(V) - P(U ∩ V) = 0.3 + 0.6 - 0.6 = 0.3.
- Answer: 0.3.

----------------------------------------------------
Q7. Given: S={0,1,2}, A={0}, B={1}, C={2}, P(A)=0.4, P(B)=0.3.
(a) P({0,1}) = P(A ∪ B) = P(A) + P(B) = 0.4 + 0.3 = 0.7.
(b) P(C) = 1 - P(A ∪ B) = 1 - 0.7 = 0.3.
(c) P(A ∪ C) = P(A) + P(C) = 0.4 + 0.3 = 0.7.
(d) P(Aᶜ) = 1 - P(A) = 1 - 0.4 = 0.6.
(e) P(Aᶜ ∩ Bᶜ) = P((A ∪ B)ᶜ) = 1 - P(A ∪ B) = 1 - 0.7 = 0.3.
(f) P(Aᶜ ∪ Bᶜ) = P((A ∩ B)ᶜ) = 1 - P(A ∩ B) = 1 - 0 = 1.

Q8. Redo #7 with P(A)=0.5, P(B)=0.4.

(b) P(C) = 1 - 0.9 = 0.1.
(c) P(A ∪ C) = 0.5 + 0.1 = 0.6.
(d) P(Aᶜ) = 1 - 0.5 = 0.5.
(e) P(Aᶜ ∩ Bᶜ) = P(C) = 0.1.
(f) P(Aᶜ ∪ Bᶜ) = 1 - P(A ∩ B) = 1 - 0 = 1.

Q9. Given: P(A)=0.4, P(B)=0.5, P(A ∩ B)=0.2.
(a) P(A ∪ B) = P(A) + P(B) - P(A ∩ B) = 0.4 + 0.5 - 0.2 = 0.7.
(b) P(Aᶜ) = 1 - P(A) = 1 - 0.4 = 0.6.
(c) P(Bᶜ) = 1 - P(B) = 1 - 0.5 = 0.5.
(d) P(Aᶜ ∩ Bᶜ) = P((A ∪ B)ᶜ) = 1 - P(A ∪ B) = 1 - 0.7 = 0.3.

Q10. Redo #9 with P(A)=0.7, P(B)=0.3, P(A ∩ B)=0.1.
(a) P(A ∪ B) = P(A) + P(B) - P(A ∩ B) = 0.7 + 0.3 - 0.1 = 0.9.
(b) P(Aᶜ) = 1 - P(A) = 1 - 0.7 = 0.3.
(c) P(Bᶜ) = 1 - P(B) = 1 - 0.3 = 0.7.
(d) P(Aᶜ ∩ Bᶜ) = P((A ∪ B)ᶜ) = 1 - P(A ∪ B) = 1 - 0.9 = 0.1.

Q11. Prove that if U ⊆ V, then P(U) ≤ P(V).
- Proof: V can be written as the disjoint union V = U ∪ (V - U).
- By Axiom 3, P(V) = P(U) + P(V - U).
- By Axiom 1, P(V - U) ≥ 0.
- Therefore, P(V) ≥ P(U).

Q13. Prove by induction that for mutually disjoint events A₁...Aₙ, P(∪Aᵢ) = ∑P(Aᵢ).
- Base Case (n=2): P(A₁ ∪ A₂) = P(A₁) + P(A₂) by Axiom 3.
- Inductive Hypothesis: Assume for n=k, P(∪Aᵢ for i=1 to k) = ∑P(Aᵢ for i=1 to k).
- Inductive Step (n=k+1): Let B = A₁ ∪ ... ∪ Aₖ. B and Aₖ₊₁ are disjoint.
  - P(A₁ ∪ ... ∪ Aₖ₊₁) = P(B ∪ Aₖ₊₁) = P(B) + P(Aₖ₊₁).
  - By hypothesis, this is (P(A₁) + ... + P(Aₖ)) + P(Aₖ₊₁).
- The formula holds for all n ≥ 2.

Q21. Coin game: Pay $1. Toss 4 times.
- 0H (P=1/16): Get $2. Net gain: $2 - $1 = +$1.
- 1H (P=4/16): Get $1. Net gain: $1 - $1 = $0.
- 2H (P=6/16): Break even. Net gain: $0.
- 3H (P=4/16): Win $3. Net gain: $3 - $1 = +$2.
- 4H (P=1/16): Win $4. Net gain: $4 - $1 = +$3.
- E = (1*1 + 0*4 + 0*6 + 2*4 + 3*1) / 16
- E = (1 + 0 + 0 + 8 + 3) / 16 = 12/16 = 3/4 = +$0.75.
- Expected gain is $0.75.
