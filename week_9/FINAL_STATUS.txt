💡 **KEY INSIGHTS NOW CLEAR:**

1. **Why BUILD-HEAP is O(n):**
   - Most nodes near bottom (leaves)
   - Only root travels full height
   - Math: Σ(h=0 to log n) [n/2^(h+1)] × h = O(n)

2. **Why heaps scale so well:**
   - 1K elements → 10 operations
   - 1M elements → 20 operations
   - 1B elements → 30 operations
   - Logarithmic = incredibly efficient!

3. **When to use heap vs sort:**
   - "Kth largest" → Heap of size k: O(n log k)
   - "Top K" → Same pattern
   - "All sorted" → Quicksort: O(n log n)
   - "Guaranteed time" → Heapsort: O(n log n)

4. **Why quicksort fails on sorted:**
   - Pivot is always min/max
   - Creates (0, n-1) split
   - Degenerates to O(n²)
   - Fix: Randomize pivot!
