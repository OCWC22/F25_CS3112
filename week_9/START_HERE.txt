⚡ KEY CONCEPTS:
----------------
**Heaps:**
- Max-heap: parent ≥ children (root = max)
- Min-heap: parent ≤ children (root = min)
- Height = O(log n) → operations are O(log n)
- BUILD-HEAP is O(n) not O(n log n)!

**Quicksort:**
- PARTITION: O(n) - split around pivot
- Average: O(n log n) with randomization
- Worst: O(n²) on sorted input (fix: randomize!)
- QuickSelect: O(n) for kth largest

💡 LEETCODE PATTERNS:
---------------------
"Kth largest" → Heap of size k: O(n log k)
"Top K elements" → Same pattern
"Merge K sorted" → Min-heap: O(M log K)
"Find median" → Two heaps (max + min)
