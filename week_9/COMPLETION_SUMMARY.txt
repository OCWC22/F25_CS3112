Time Complexity Cheat Sheet:
-----------------------------
HEAPS:
- Build heap: O(n) ← Surprisingly fast!
- Insert: O(log n)
- Extract-max: O(log n)
- Heapify: O(log n)
- Heapsort: O(n log n) always

QUICKSORT:
- Average case: O(n log n)
- Worst case: O(n²) ← Avoid with randomization
- Best case: O(n log n)
- Partition: O(n)

Common Mistakes to Avoid:
-------------------------
❌ Using sorting when heap is faster (Kth largest)
❌ Using heap when array is already sorted
❌ Forgetting to randomize quicksort pivot
❌ Not recognizing O(n) heap building vs O(n log n) sorting
❌ Confusing when to bubble up vs bubble down
❌ Thinking quicksort is always O(n log n)
