Time Complexity Cheat Sheet:
-----------------------------
HEAPS:
- Build heap: O(n) ← Surprisingly fast!
- Insert: O(log n)
- Extract-max: O(log n)
- Heapify: O(log n)
- Heapsort: O(n log n) always

QUICKSORT:
- Average case: O(n log n)
- Worst case: O(n²) ← Avoid with randomization
- Best case: O(n log n)
- Partition: O(n)

Common Mistakes to Avoid:
-------------------------
❌ Using full sort for "kth largest" → Use heap of size k: O(n log k)
❌ Building heap with n inserts → Use BUILD-HEAP: O(n) not O(n log n)
❌ Forgetting to randomize quicksort → O(n²) on sorted input
❌ Using quicksort when need guaranteed O(n log n) → Use heapsort
❌ Confusing when to bubble up vs sink down → Insert=up, Heapify=down
❌ Thinking quicksort is always O(n log n)
