### Technical Highlights:

**Divide-and-Conquer Key Points:**
- Three steps: divide, conquer, combine
- Recursive structure
- Base case essential
- Often achieves better asymptotic performance

**Merge Sort Key Points:**
- Divides in half each time
- Sorts recursively
- Merges in linear time
- Always Θ(n lg n) (all cases)
- Requires Θ(n) extra space
- Stable sort

**MERGE Procedure Key Points:**
- Copies to temporary arrays L and R
- Three while loops (main + two cleanup)
- Compares smallest remaining elements
- Linear time: Θ(n) where n = r - p + 1
- Critical to correctness

**Recurrence Analysis Key Points:**
- T(n) = 2T(n/2) + Θ(n) for merge sort
- Recursion tree: lg n levels, cn cost per level
- Total: cn lg n = Θ(n lg n)
- Master Theorem: Case 2 with k=0

**Binary Search Key Points:**
- Requires sorted array
- Eliminates half each iteration
- T(n) = T(n/2) + Θ(1)
- Solution: Θ(lg n)
- Much faster than linear search

### Problem-Specific Insights:

**2.3-1 (Trace merge sort):**
- Input: [3, 41, 52, 26, 38, 57, 9, 49]
- Divide to 8 single elements
- Merge pairs: [3,41], [26,52], [38,57], [9,49]
- Merge fours: [3,26,41,52], [9,38,49,57]
- Final merge: [3,9,26,38,41,49,52,57]

**2.3-2 (Base case sufficiency):**
- Initial call has p ≤ r (given n ≥ 1)
- Recursive calls maintain p ≤ q and q+1 ≤ r
- Therefore p > r never occurs
- "if p ≠ r" sufficient (though "if p ≥ r" is safer)

**2.3-3 (MERGE loop invariant):**
- Invariant: A[p:k-1] has k-p smallest elements, sorted
- Main loop merges while both arrays have elements
- Cleanup loops copy remaining elements
- Result: A[p:r] fully sorted

**2.3-4 (Solve recurrence by induction):**
- Claim: T(n) = n lg n + n for powers of 2
- Base: T(2) = 4 = 2 lg 2 + 2 ✓
- Inductive: T(n) = 2T(n/2) + n = n lg n + n ✓
- Result: Θ(n lg n)

**2.3-5 (Recursive insertion sort):**
- Sort A[1:n-1], then insert A[n]
- Recurrence: T(n) = T(n-1) + Θ(n)
- Solution: T(n) = Θ(n²)
- Same as iterative version

**2.3-6 (Binary search):**
- Check middle, eliminate half
- Recursive or iterative implementation
- T(n) = T(n/2) + Θ(1) → Θ(lg n)
- Fundamental searching algorithm

**2.3-7 (Binary search in insertion sort):**
- Comparisons improve: Θ(n²) → Θ(n lg n)
- Shifts unchanged: Θ(n²)
- Total: Θ(n²) (no asymptotic improvement)
- Bottleneck is shifting, not finding

**2.3-8 (Two-sum problem):**
- Sort array: Θ(n lg n)
- Two-pointer scan: Θ(n)
- Total: Θ(n lg n)
- Alternative: Sort + binary search also Θ(n lg n)
