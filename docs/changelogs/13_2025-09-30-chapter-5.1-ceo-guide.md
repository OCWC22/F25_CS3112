## 💡 Key Insights

### Pattern Recognition
1. **Alternating signs**: Use (-1)^k or (-1)^(k+1)
2. **Factorial simplification**: Cancel before multiplying
3. **Binomial symmetry**: C(n,r) = C(n,n-r)

### Calculation Strategies
1. **Summations**: Expand, simplify, use formulas
2. **Products**: Look for telescoping
3. **Factorials**: Use recursive property
4. **Combinations**: Cancel early, use symmetry

### Memory Techniques
1. **Σ = Sum** (add them up)
2. **Π = Product** (multiply them all)
3. **n! = Arrangements** (lineup problem)
4. **C(n,r) = Selections** (committee problem)
