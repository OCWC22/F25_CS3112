### Technical Highlights:

**Section 4.1 Key Concepts:**
- 8 subproblems from 4 output submatrices × 2 products each
- Index calculation: Θ(1) partition, O(1) space
- Copying: Θ(n²) partition, O(n²) space
- Both give T(n) = Θ(n³) (same asymptotic time)
- Non-square matrices: result size determines complexity

**Section 4.2 Key Concepts:**
- 7 products instead of 8 → exponent 2.807 instead of 3
- Trade-off: -1 multiplication, +14 additions
- Algebraic verification shows terms cancel correctly
- Practical: only faster for large n (>100-1000)
- Complex numbers: same principle (4 → 3 multiplications)

**Section 4.3 Key Concepts:**
- Guess form with explicit constants
- Prove by mathematical induction
- Subtract lower-order terms when simple guess fails
- Never use asymptotic notation in hypothesis
- Must prove exact form of claim

### Problem-Specific Insights:

**4.1-1 (Non-powers of 2):**
- Use ⌈n/2⌉ and ⌊n/2⌋ for unequal splits
- Still Θ(n³) despite unequal submatrices
- Ceiling/floor add at most constant overhead

**4.1-2 (Non-square matrices):**
- (kn×n) × (n×kn) → kn×kn result → Θ(k²n³)
- (n×kn) × (kn×n) → n×n result → Θ(kn³)
- Second is k times faster (smaller output)

**4.1-3 (Copying analysis):**
- Copying adds Θ(n²) per level
- Doesn't change Θ(n³) result (8 subproblems dominate)
- More space, same asymptotic time

**4.1-4 (Matrix addition):**
- With index: T(n) = 4T(n/2) + Θ(1) → Θ(n²)
- With copying: T(n) = 4T(n/2) + Θ(n²) → Θ(n² lg n)
- Copying DOES matter for addition (fewer subproblems)

**4.2-1 (Manual computation):**
- Execute on 2×2 matrices (1×1 submatrices)
- Careful arithmetic with negatives
- Verify with standard multiplication

**4.2-3 (k×k base case):**
- T(n) = kT(n/3) + Θ(n²)
- For o(n^(lg 7)): need k ≤ 21
- Optimal: k=21 gives Θ(n^2.771)

**4.2-4 (Pan's algorithms):**
- All three give same exponent (≈2.795)
- Slightly better than Strassen (2.807)
- Impractical due to huge constants

**4.2-5 (Complex numbers):**
- Standard: 4 real multiplications
- Trick: P₃ = (a+b)(c+d), recover ad+bc
- Result: 3 real multiplications

**4.2-6 (Squaring subroutine):**
- Square augmented matrix [0 A; B 0]
- Result has AB in top-right block
- Time: Θ(n^α) same as squaring

**4.3-1 (Multiple proofs):**
- Each requires different technique
- Some need lower-order terms
- Some need both O and Ω for Θ

**4.3-2 (Show failure):**
- Simple cn² gets cn² + n (fails)
- Modified cn² - dn absorbs the +n
- Demonstrates the technique

**4.3-3 (Exponential):**
- Simple c·2ⁿ gets c·2ⁿ + 1 (fails)
- Modified c·2ⁿ - d absorbs the +1
- Even constants matter with exponentials

### Key Formulas Summary:

**Strassen's 7 Products:**
```
P₁ = A₁₁(B₁₂ - B₂₂)
P₂ = (A₁₁ + A₁₂)B₂₂
P₃ = (A₂₁ + A₂₂)B₁₁
P₄ = A₂₂(B₂₁ - B₁₁)
P₅ = (A₁₁ + A₂₂)(B₁₁ + B₂₂)
P₆ = (A₁₂ - A₂₂)(B₂₁ + B₂₂)
P₇ = (A₁₁ - A₂₁)(B₁₁ + B₁₂)
```

**Strassen's Combinations:**
```
C₁₁ = P₅ + P₄ - P₂ + P₆
C₁₂ = P₁ + P₂
C₂₁ = P₃ + P₄
C₂₂ = P₅ + P₁ - P₃ - P₇
```

**Recurrences:**
```
Standard D&C: T(n) = 8T(n/2) + Θ(n²) → Θ(n³)
Strassen: T(n) = 7T(n/2) + Θ(n²) → Θ(n^2.807)
```

**Substitution Method:**
```
1. Guess: T(n) ≤ cf(n)
2. Prove by induction
3. If fails: try cf(n) - (lower-order)
```
