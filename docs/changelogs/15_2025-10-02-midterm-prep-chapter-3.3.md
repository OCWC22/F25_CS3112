### Key Decisions & Trade-offs:

**Decision 1: Problem Type Taxonomy**
- Created 8 distinct problem types based on homework images
- Each type has: recognition pattern, mental model, solution approach, examples
- **Trade-off:** More categories = more to remember, but clearer problem-solving paths
- **Rationale:** Student needs systematic approach to identify and solve problems under time pressure

**Decision 2: JIT Learning Approach**
- Focus on "why" and "how to recognize" rather than just "what"
- Connect concepts to practical algorithm analysis
- Build mental models for intuition
- **Trade-off:** Longer initial read time, but deeper understanding and better retention
- **Rationale:** Student explicitly requested JIT learning to connect the dots

**Decision 3: Three-Tier Material Structure**
- Comprehensive guide for deep learning (50+ pages)
- Detailed solutions for homework problems (40+ pages)
- Quick cheat sheet for exam reference (5 pages)
- **Trade-off:** More files to manage, but serves different study phases
- **Rationale:** Different materials for different study modes (learning, practicing, reviewing)

**Decision 4: Emphasis on Problem Recognition**
- Each problem type has clear "recognition pattern" section
- Keywords, common phrases, and structural cues highlighted
- **Trade-off:** May seem formulaic, but critical for exam speed
- **Rationale:** Midterm time pressure requires quick problem identification

**Decision 5: Complete Proofs for All 6 Problems**
- Solved all problems from homework images (3.3-1 through 3.3-6)
- Multiple proof approaches where applicable

- **Trade-off:** Very detailed (may be overwhelming), but comprehensive
