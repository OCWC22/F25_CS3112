### Technical Highlights:

**Insertion Sort Key Points:**
- Starts at i=2 (first element already sorted)
- Saves A[i] as key before shifting
- Shifts elements right while A[j] > key
- Inserts key at position j+1
- In-place algorithm (O(1) extra space)

**Loop Invariant Key Points:**
- Property true before and after each iteration
- Like mathematical induction (base + inductive step)
- Three properties required for correctness proof
- Must include "original elements" (permutation property)
- Termination property gives final result

**Running Time Key Points:**
- Best case Θ(n): already sorted, no shifts
- Worst case Θ(n²): reverse sorted, maximum shifts
- Average case Θ(n²): random order, about half worst case
- Efficient for small arrays (n < 50)
- Stable sort (preserves relative order of equal elements)

### Problem-Specific Insights:

**2.1-1 (Trace execution):**
- Input: [31, 41, 59, 26, 41, 58]
- Key iteration: i=4 where 26 moves to front
- Shows worst-case behavior for one element
- Final: [26, 31, 41, 41, 58, 59]

**2.1-2 (SUM-ARRAY invariant):**
- Simple accumulation pattern
- Invariant: sum = A[1] + ... + A[i-1]
- Empty subarray sum is 0 (initialization)
- Shows loop invariants work for any loop

**2.1-3 (Decreasing order):**
- Minimal change: one comparison operator
- A[j] > key → A[j] < key
- Same structure, opposite result
- Shows power of small changes

**2.1-4 (Linear search):**
- Sequential scan from left to right
- Return index if found, NIL if not
- Invariant: A[1:i-1] doesn't contain x
- Termination: either found or checked all

**2.1-5 (Binary addition):**
- Work right-to-left (least significant first)
- Carry propagates left
- sum mod 2 gives bit, ⌊sum/2⌋ gives carry
- Result array one bit longer (n+1)
- Example: 1011 + 0111 = 10010 (11 + 7 = 18)

```

Average case: Θ(n²)

Worst case comparisons: 1 + 2 + ... + (n-1) = n(n-1)/2
```

**Loop Invariant Structure:**
```
1. Initialization: True before first iteration
2. Maintenance: True before → True after
3. Termination: Invariant + exit condition → correctness
```

**Binary Addition:**
```
sum = A[i] + B[i] + carry
C[i] = sum mod 2
carry = ⌊sum / 2⌋
```
