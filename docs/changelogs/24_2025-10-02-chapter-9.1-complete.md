### Technical Highlights:

**Probability Key Points:**
- Sample space = all possible outcomes
- Event = subset of sample space
- P(E) = N(E)/N(S) when equally likely
- 0 ≤ P(E) ≤ 1 always
- Complement: P(not E) = 1 - P(E)

**Counting Key Points:**
- Integers from m to n: n - m + 1
- Must include both endpoints
- Common mistake: forgetting +1
- Applies to array subarrays

**Array Key Points:**
- A[1] to A[n]: n elements
- A[m] to A[k]: k - m + 1 elements
- Even subscripts: ⌊n/2⌋ elements
- First half: ⌊n/2⌋ elements
- Second half: ⌈n/2⌉ elements

**Multiples Key Points:**
- First multiple ≥ m: ⌈m/d⌉ × d
- Last multiple ≤ n: ⌊n/d⌋ × d
- Count: ⌊n/d⌋ - ⌈m/d⌉ + 1
