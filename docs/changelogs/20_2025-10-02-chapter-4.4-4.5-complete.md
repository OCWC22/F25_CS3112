### Technical Highlights:

**Section 4.4 Key Concepts:**
- Recursion tree = visual representation of recurrence
- Cost per level = (# nodes) × (cost per node)
- Height = log_b n for divide-by-b recurrences
- Three patterns: decreasing (r<1), constant (r=1), increasing (r>1)
- Ratio test: r = (cost at level i+1)/(cost at level i)
- Always verify guess with substitution method

**Section 4.5 Key Concepts:**
- Watershed function: n^(log_b a)
- Case 1: f(n) polynomially smaller → leaves dominate
- Case 2: f(n) same rate (up to logs) → all levels equal
- Case 3: f(n) polynomially larger + regularity → root dominates
- Polynomial separation: difference of n^ε for some ε > 0
- Regularity: af(n/b) ≤ cf(n) for some c < 1

### Problem-Specific Insights:

**4.4-1(a): T(n) = T(n/2) + n³**
- Single path tree (no branching)
- Costs: n³, n³/8, n³/64, ...
- Geometric series with r = 1/8 < 1
- Root dominates → Θ(n³)

**4.4-1(b): T(n) = 4T(n/3) + n**
- 4-way branching, divide by 3
- Costs: n, 4n/3, 16n/9, ...
- Ratio r = 4/3 > 1 (increasing)
- Leaves dominate → Θ(n^(log₃ 4)) ≈ Θ(n^1.262)

**4.4-1(c): T(n) = 4T(n/2) + n**
- 4-way branching, divide by 2
- Costs: n, 2n, 4n, 8n, ...
- Ratio r = 2 > 1 (doubling)
- Leaves dominate → Θ(n²)

**4.4-1(d): T(n) = 3T(n-1) + 1**
- Linear decrease with branching
- Exponential growth: 3^i nodes at level i
- Height n → total Θ(3^n)

**4.4-2: L(n) = L(n/3) + L(2n/3) + 1**
- Prove L(n) = Ω(n) for leaf count
- Key: n/3 + 2n/3 = n (subproblems sum to original)
- Lower bound proof straightforward

**4.4-3: T(n) = T(n/3) + T(2n/3) + cn**
- Unbalanced tree, but cost per level always cn
- Height Θ(lg n) → total Θ(n lg n)
- Split ratio doesn't matter asymptotically!

**4.4-4: T(n) = T(αn) + T((1-α)n) + Θ(n)**
- General unbalanced split
- Cost per level always Θ(n)
- Height always Θ(lg n) for any 0 < α < 1
- Result always Θ(n lg n)

**4.5-1: Same a, b, Different f(n)**
- All have a=2, b=4 → watershed √n
- (a) f(n)=1: Case 1 → Θ(√n)
- (b) f(n)=√n: Case 2 → Θ(√n lg n)
- (c) f(n)=n: Case 3 → Θ(n)
- (d) f(n)=n²: Case 3 → Θ(n²)
- Shows how f(n) determines case!

**4.5-2: Caesar's Algorithm**
- Design constraint: beat Strassen's Θ(n^2.807)
- Recurrence: aT(n/4) + Θ(n²)
- Need: n^(log₄ a) < n^2.807
- Solve: a < 4^2.807 ≈ 48.85
- Answer: a = 48 (largest integer)

**4.5-3: Binary Search**
- Classic: T(n) = T(n/2) + Θ(1)
- Watershed: n^(log₂ 1) = 1
- Case 2 with k=0 → Θ(lg n)
- Confirms logarithmic search time

**4.5-4: Logarithm Failures**
- f(n) = lg n doesn't satisfy Case 3
- Regularity fails: ratio → 1 (not < 1)
- Polynomial fails: lg n = o(n^ε) for any ε > 0
- Falls in gap between cases

**4.5-5: Oscillating Function**
- f(n) = 2^(⌈lg n⌉) is large but not regular
- Polynomial condition satisfied
- Regularity fails due to ceiling function
- Shows why both conditions needed

### Key Formulas Summary:

**Recursion Trees:**
```
Height (divide by b): log_b n
Nodes at level i: a^i
Cost at level i: a^i × f(n/b^i)
Ratio: r = (cost at i+1)/(cost at i)

r < 1: Root dominates
r = 1: All equal
r > 1: Leaves dominate
```

**Master Method:**
```
Given: T(n) = aT(n/b) + f(n)
Watershed: n^(log_b a)

Case 1: f(n) = O(n^(log_b a - ε))
        → T(n) = Θ(n^(log_b a))

Case 2: f(n) = Θ(n^(log_b a) × (lg n)^k)
        → T(n) = Θ(n^(log_b a) × (lg n)^(k+1))

Case 3: f(n) = Ω(n^(log_b a + ε)) AND af(n/b) ≤ cf(n)
        → T(n) = Θ(f(n))
```

**Common Watersheds:**
```
log₂ 2 = 1 → n^1 = n
log₂ 4 = 2 → n^2
log₂ 8 = 3 → n^3
log₂ 7 ≈ 2.807 → n^2.807
log₄ 2 = 0.5 → √n
```
